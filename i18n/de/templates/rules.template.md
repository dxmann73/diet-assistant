# Persönliche Regeln

Deine Vorlieben. Sie haben Vorrang vor den Vorgaben in `AGENTS.md`. Der Assistent ergänzt hier
eine Regel, wenn du ihm etwas ohne Zahl oder ID beibringst („ab jetzt …“, „merke dir, dass …“).
Regeln mit einer Zahl oder ID (Mengen, MET-Werte, tägliche Standardeinträge) gehören stattdessen
in `habits.json`.

## Antwortstil

- Kurz und verständlich.

## Reihenfolge des Berichts

In jedem Bericht:

1. Das Diagramm: direkt im Chat, wenn der Agent es anzeigen kann, sonst ein Hinweis auf
   `charts/chart-cdn.html`.
2. Offene Fragen, alle auf einmal. Überspringe diesen Punkt, wenn es keine gibt.
3. Das Defizit des Tages, dann der Rest der Bilanz.
